## 2. Operational safety

-   Never print secrets, tokens, connection strings, or .env values.
-   No service restarts, no Windows Firewall changes, no destructive DB
    commands or migrations.
-   Keep flags false: ENABLE_EXPERIMENTAL_MODULAR_DETECTORS,
    ENABLE_REAL_WINDOWS_FIREWALL_ENFORCEMENT, and the
    autonomous-containment flag. Grep for the exact flag names in code;
    if a name in this contract does not exist, report that instead of
    assuming.

-   Never fabricate IPs, timestamps, traffic, attack records, hashes,
    file paths, line numbers, or command output.
-   Synthetic replay is never real-traffic evidence.
-   Tests may run only after Phase 1 establishes a safe strategy, and
    only against temp copies / tmp_path for anything Q-table related.

## 3. Evidence discipline

Status labels: CONFIRMED, PARTIALLY CONFIRMED, INFERRED, UNVERIFIED,
BLOCKED, PASS, FAIL, NOT EVALUATED, FORMALLY RE-SCOPED, INCONCLUSIVE
(Wilson CI straddles target). Each substantive finding records: claim,
evidence source, verification method, result, status, remaining
uncertainty, next action. Unit tests passing is engineering completion,
not detector acceptance.

## 4. Single source of truth for numbers (hard rule)

Every number in any report must be generated by a script into a
metrics.json (or per-phase JSON). Reports and tables are rendered from
that file, never hand-typed. Record for each command: exact command,
exit code, timestamp, environment, raw log path.

## 9. Execution

One phase per run. Inspect, state intended change and risk, make the
smallest justified fix, run narrowest tests, verify protected hashes,
save raw outputs, write HANDOFF.md, stop. Pause only for: integrity
incidents, destructive operations, owner-only decisions, missing
data/credentials, downloads over 20 GB total, security-enforcement
changes.

Downloads: verify authoritative source, version, license, published
checksum, disk space; download into a new non-protected folder; prefer
one representative day per attack type over whole corpora; never execute
unknown files.
